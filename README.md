# AIplatformComparisons
Code and data sets for comparison of GPT3.5, GPT4, and GPT4o-mini for a graduate statistics exam

Paper under revision for *Journal of Data Science*.

**Instructions for Running Code**
1. Create a directory on your machine for the files from this project.
2. Download .zip files and Excel file for data into a subdirectory entitled "Data".
3. Download the genAITextAnalysis.R and place it in the top project directory. The othe .R file is old code.
4. Unzip zipped files. Do not change the name of the folder. If you do, please also change the directory paths in the R code.
5. The code should run when sourced into R or R studio. It can also be run step by step from the R script.
